# Abalon Entertainment — early website archive

A restoration of six saved pages from the late-1990s/early-2000s Korean Abalon Entertainment website, featuring company news, an introduction and history, and material about the RPG **Dispel**. The source is a local backup of Internet Archive captures from different dates. The original home page was not included; the archive opens on News.

## What has been added

- Local navigation between the available News, company Introduction, Game, Story, Features and Gallery pages.
- An English/Korean switch with local English translations of the available Korean page text. The English is a modern reconstruction and may contain translation errors; text embedded in historical images is not translated.
- Replacements for missing navigation and decorative graphics, plus clearly labeled placeholders for unavailable large images. Several recovered screenshot thumbnails come from the separate English Dispel archive, and some character thumbnails use images from the existing Abalon archive.
- Selectable Recovered, 90s Tech, Late 90s, Stone, Rough Stone and Dark Fantasy appearances; the latter designs are interpretations based on supplied references. The Appearance menu also offers text and three alternative Abalon logos. Choices are retained through the archive's internal links.
- Locally hosted fonts for the appearances; their Open Font License notices are included in `fonts/`.

Some links lead to historical Wayback Machine captures or unavailable services. Crossed-out links are retained for historical context and may no longer work. Thumbnail popups for missing full-size images display placeholders rather than recovered artwork. Linked images from the other Abalon archive require network access. The site is an unofficial historical reconstruction, not an active game studio website.

## Local viewing and hosting

Open `index.html` in a browser, or serve this folder as a static website. The archive contains no server-side code. GitHub Pages can publish it directly from the repository's `main` branch and root folder.
